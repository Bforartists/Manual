## Power User Tools

![Power User Tools](/docs2/images/extensions/bforartists-extensions/core-extension-power-user-tools/power-user-tools.png)

This addon is optional and deactivated by default.

This is an addon with an additional set of user experience tools and operators to assist every day use.

This addon is thanks to Andres Stephens (Draise).

> **Note:** To activate/deactivate an addon, go to Edit – Preferences – Addons tab – and untick any activated addons.
>
> If you’d like to keep your addons for future use, you can either **save the preferences**, or activate them on demand per workspace in the workspace settings in the property shelf.

## Preferences

![Preferences](/docs2/images/extensions/bforartists-extensions/core-extension-power-user-tools/preferences.png)

In the addon preferences, you can toggle which group of operators or user experience customization to help assist your needs.

![Animation](/docs2/images/extensions/bforartists-extensions/core-extension-power-user-tools/animation.png)

## Operators

### Animation Operators

#### Insert Frame Left

![Insert Frame Left](/docs2/images/extensions/bforartists-extensions/core-extension-power-user-tools/frames-insert-remove-operators-toggle.png)

Inserts an empty frame and nudges all frames to the left of the time cursor. Useful for grease pencil and stop motion animation.


| Entry | What it does |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Remove Frame Left | Removes a frame on the right of the timeline cursor and nudges all frames towards the timeline cursor. **Note:** C*urrent frame on timeline cursor will be removed.* |
| Insert Frame Right | Inserts an empty frame and nudges all frames to the right of the time cursor Useful for grease pencil and stop motion animation. |
| Remove Frame Right | Removes a frame on the right of the timeline cursor and nudges all frames towards the timeline cursor. ***Note:** Current frame on timeline cursor will be removed.* |


#### Jump Frame Left

![Jump Frame Left](/docs2/images/extensions/bforartists-extensions/core-extension-power-user-tools/jump-frame-left.png)

Move the timeline cursor to the left and jump by the number of frames defined in the center property.

#### Jump Frame Right

Move the timeline cursor to the right and jump by the number of frames defined in the center property.

### Custom Operators

#### Combine Viewport/Render Subdivision Levels

When applying modifier levels using hotkeys in the 3D View to adjust the Subdivision Modifier levels, this will set the render levels to match the viewport subdivision levels.

> **Note:** Use the Bforartists hotkeys **CTR+1, 2, 3,...** to toggle the subdivision levels directly from the 3D View editor.

### Viewport Operators

#### Viewport Silhuette Toggle

![Viewport Silhuette Toggle](/docs2/images/extensions/bforartists-extensions/core-extension-power-user-tools/viewport-silhuette-toggle.png)

Adds the viewport overlay silhuette toggle to the header of the 3D View editors. Located in the header overlays row to the top right.

### File Operators

![File Operators](/docs2/images/extensions/bforartists-extensions/core-extension-power-user-tools/file-operators.png)

#### Open Blend File Folder

Adds an operator to open the current blend file folder in the File Explorer of your operating system. Located in the File header menu under the External Data sub-menu.

## Use

### 1. Activate the addon

In the user preferences Addons tab, search for “Power User” and activate the addon.

![1. Activate the addon](/docs2/images/extensions/bforartists-extensions/core-extension-power-user-tools/1-activate-the-addon.png)

### 2. Customize which operators you would need in the preferences

Here you will find categories and groups of operators. Mouse over which group of operators to see the tooltip to learn more.
