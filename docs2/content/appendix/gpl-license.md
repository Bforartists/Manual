Bforartists is free and open-source software, released under the **GNU General Public License (GPL)**, version 3 or later, like Blender, which it is based on.

> **Draft:** this page will be reviewed before release.

## What the GPL means for you

- **Use it for anything:** personal work, commercial work, teaching and studio pipelines, with no fees and no limits.
- **Your art is yours:** the GPL covers the software, not what you make with it. Renders, models, animations and .blend files you create belong to you.
- **Share and change it:** you may copy Bforartists, give it away, and change its source code.
- **Keep it free:** if you distribute a changed version of Bforartists, you must share its source code under the same license.

## Add-ons and scripts

Python add-ons that use the Bforartists API are generally considered to be covered by the GPL when they are distributed. Assets, textures and .blend files are not.

## Read the license

The full text is on the GNU website (https://www.gnu.org/licenses/gpl-3.0.html) and in the license files that come with Bforartists.
