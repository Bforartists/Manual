This is the official **reference manual** for Bforartists 5. This explains the tools, operators, panels, and concepts you’ll encounter in the software. Each chapter and section is designed to help you understand how features work and how to use them effectively in detail.

What this documentation is not: this is not a general art tutorial. You won’t find step‑by‑step lessons on how to create a finished artwork here. Instead, you’ll find the technical knowledge you need to make the tools work to later make art efficiently with full control.

For creative fundamentals, the Blender community offers countless tutorials and a rich ecosystem courses that translate seamlessly into Bforartists workflows.

### Bforartists is a free and open‑source 3D creation suite built on top of Blender.

![Blender with Bforartists](https://cdn.prod.website-files.com/650c5901cff33429a5e537f5/6a44625ec0e0fb08a9b1caab_Blender%26Bforaritsts.png)

Its mission is to provide an **accessible user experience with mouse/stylus first**, **visual** and **artist‑friendly interface,** with **out-of-the-box convenience assets and functionality** while keeping the full power of Blender’s production pipeline. Whether you’re modeling, sculpting, animating, or compositing, Bforartists offers a streamlined workflow with a focus on day to day usability.

Bforartists stands for **"Be for Artists"**, a reminder to develop for the artist.

### The project exists to make 3D creation approachable to visually focused artists.

Blender is powerful, but its interface can be overwhelming. Bforartists simplifies menus, improves readability, exposes common operators to a top levels, adds out-of the box assets and convenience tools, and reduces clutter - so artists can focus on creativity instead of fighting the UI. It’s designed for professionals and hobbyists alike who want the freedom of open‑source software with a friendlier learning curve while maintaining full ultimate control for artistry.

If you’re new, start with the the **Getting Started** section, then move onto each **Interface** element and **Workspaces.** Each Workspace can help you get started for their particular usecases.

These cover navigation, panels, and the basics of working in Bforartists. Once you’re comfortable, explore each **Editor**, which dive into each shelf, panel and its tools with detail of properties per editor.

Use the search to the top right if you are looking for something specific.

This manual will guide you through every operator and panel, editor, shelf and interface element. Expect concise explanations, screenshots, videos, gifs and references to help you understand what each tool does. You’ll learn how to activate features, adjust settings, and integrate them into your workflow.

### The Bforartists 5 Reference Manual

#### Version 5.1.1

### Introduction

![Introduction](/docs2/images/getting-started/introduction/introduction-2.png)

Welcome to the reference manual for Bforartists 5, the free and open source 3D creation suite.

First let's explain what the manual is and what it is not: this is a reference manual. This means every chapter lists and explains the available tools, operators, the interface and general concepts.

What his is not: this is not a general CG tutorial. This manual will not explain workflows on how to create artwork. If you’d like to learn the creative fundamentals, there are numerous courses and tutorials for Blender from the community which will translate to Bforartists workflows seamlessly. This manual does however cover the needed workflow to get a tool working or explains how the tool is meant to work.

Chapters 1 to 5 covers general interface fundamental concepts. Chapters 6 to 30 explain the single editors and their tools. And every chapter afterwards is additional information.

This reference manual is for Bforartists 5 version 5.1.1 published on 23.04.2026
