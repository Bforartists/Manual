## Dopesheet Editor - Channel List

![Dopesheet Editor - Channel List](/docs2/images/editors/dope-sheet/channel-list/dopesheet-editor-channel-list.png)

The channel list contains your objects and their animation channels. See also the different modes.

The channel list area can be resized by dragging the right border to left or right.

The list has several elements, to turn on or off different features, Or to expand or collapse the hierarchy.

### Hotkeys

![Hotkeys](/docs2/images/editors/dope-sheet/channel-list/hotkeys.png)

Hotkey A selects all channels.

Hotkey Alt A deselects everything.

Left mouse and dragging activates box select.

Clicking at a channel selects it.

Clicking at a channel while holding down shift adds to the selection or removes from the selection.

### Search field

![Search field](/docs2/images/editors/dope-sheet/channel-list/search-field.png)

At the top is a search field that allows you to filter the channel list by search terms.

#### Invert

Inverts the search result.

### Expand / collapse triangle

![Expand / collapse triangle](/docs2/images/editors/dope-sheet/channel-list/expand-collapse-triangle.png)

The triangle icon at the left allows you to expand or collapse the hierarchy.

### Pin

![Pin](/docs2/images/editors/dope-sheet/channel-list/pin.png)

Keep the channels visible in Graph Editor for editing.

### Object type Icon

![Object type Icon](/docs2/images/editors/dope-sheet/channel-list/object-type-icon.png)

This icon shows what kind of object this channel belongs to. These icons have no functionality.

### Channel name

![Channel name](/docs2/images/editors/dope-sheet/channel-list/channel-name.png)

The name of the channel name and element. Some elements can be renamed. Like the action or object type.

To rename an element double click at it. Type in the new name. Then press Enter or click elsewhere.

### Enable F-Curve Modifiers

![Enable F-Curve Modifiers](/docs2/images/editors/dope-sheet/channel-list/enable-f-curve-modifiers.png)

![Enable F-Curve Modifiers](/docs2/images/editors/dope-sheet/channel-list/enable-f-curve-modifiers-2.png)

In the Graph editor you can add F-Curve modifiers. In the other animation editor types, like the Dope Sheet editor, you can enable or disable these modifiers by the Enable F-Curve Modifiers setting in the channel list.

For further informations about the F-Curve modifiers see the graph editor chapters.

### Mute Channel

![Mute Channel](/docs2/images/editors/dope-sheet/channel-list/mute-channel.png)

Mutes the selected channel. It will not be calculated.

### Lock Channel

![Lock Channel](/docs2/images/editors/dope-sheet/channel-list/lock-channel.png)

Locks the selected channel. It is not longer editable.

### Slider values

![Slider values](/docs2/images/editors/dope-sheet/channel-list/slider-values.png)

![Slider values](/docs2/images/editors/dope-sheet/channel-list/slider-values-2.png)

F-Curves can show a slider value in the channel list. This can be adjusted in the sidebar in the View options panel. Show Sliders is off by default.

You can edit these values. Double click to make it editable. Enter or click elsewhere to confirm. When you confirm, then the original keyframe gets updated.

When no keyframe exists at the current position, then this keyframe gets created.

### Shape key values

![Shape key values](/docs2/images/editors/dope-sheet/channel-list/shape-key-values.png)

Shape key mode only.

In Shape key mode the channels shows the blend value. You can also edit it. Double click to make it editable. Enter or click elsewhere to confirm. When you confirm, then the original keyframe gets updated.

When no keyframe exists at the current position, then this keyframe gets created.

### Opacity values

![Opacity values](/docs2/images/editors/dope-sheet/channel-list/opacity-values.png)

Grease Pencil only.

In Grease Pencil mode the channels shows the opacity values. You can also edit it. Double click to make it editable. Enter or click elsewhere to confirm. When you confirm, then the original keyframe gets updated.

When no keyframe exists at the current position, then this keyframe gets created.

### Mask Layer

![Mask Layer](/docs2/images/editors/dope-sheet/channel-list/mask-layer.png)

Grease Pencil only.

Mask pixels from underlying drawing layers.

### Onion Skinning

![Onion Skinning](/docs2/images/editors/dope-sheet/channel-list/onion-skinning.png)

Grease Pencil only.

Display onion skins ghost frames from before and after the current frame.
