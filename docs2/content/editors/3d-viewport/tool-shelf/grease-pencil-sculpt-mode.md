## Tool Shelf - Grease Pencil - Sculpt Mode

![Tool Shelf - Grease Pencil - Sculpt Mode](/docs2/images/editors/3d-viewport/tool-shelf/grease-pencil-sculpt-mode/tool-shelf-grease-pencil-sculpt-mode.png)

In Sculpt Mode you will mainly find brushes in the tool shelf.

The brushes settings are covered in the chapter 25.1.8 Editors - Properties Editor - Tools Tab - Grease Pencil Object.

### Brush

![Brush](/docs2/images/editors/3d-viewport/tool-shelf/grease-pencil-sculpt-mode/brush.png)

Sculpt brushes.

The brushes names are pretty self expanatory

### Clone

![Clone](/docs2/images/editors/3d-viewport/tool-shelf/grease-pencil-sculpt-mode/clone.png)

![Clone](/docs2/images/editors/3d-viewport/tool-shelf/grease-pencil-sculpt-mode/clone-2.png)

Clones strokes. You first need to copy a stroke before you can clone it in sculpt mode.

This can be done in edit mode. Or you switch to one one of the mask selection modes. Then select a stroke. With circle select for example. Copy it with ctrl c. And then you should be able to clone the current stroke around with a mouse click.

Note that it clones the whole stroke, and not just the selected stroke geometry. The clone brush is more of a copy and paste stroke tool.

### Annotate tools

The annotate tools at the end of the list are explained in the chapter 7.1.1 Editors - 3D View - Tool Shelf - Object Mode. We won't cover this tools again here.

However, the active tool setting in Sculpt mode has an extra setting.

### Select tools

![Select tools](/docs2/images/editors/3d-viewport/tool-shelf/grease-pencil-sculpt-mode/select-tools.png)

The select tool appears when you are in one of the mask selection modes. It allows you to select strokes.

![Select tools](/docs2/images/editors/3d-viewport/tool-shelf/grease-pencil-sculpt-mode/clone-2.png)

Like the annotate tools they are already explained in the chapter 7.1.1 Editors - 3D View - Tool Shelf - Object Mode. We won't cover this tools again here.
