**Markers** are labels on important frames, for example the start of an action or the end of a camera move. Adding the first one shows a marker row at the bottom of the editor.

Drag a marker to move it. The active marker is yellow. Hold :kbd[Shift] to select more than one.

| Menu entry | What it does |
|---|---|
| Add Marker | Adds a marker at the current frame |
| Duplicate Marker | Duplicates the selected markers. They follow the mouse until you click |
| Duplicate Marker to Scene | Copies the selected markers to another scene in the file |
| Delete Marker | Deletes the selected markers |
| ![](/docs2/images/ui/shared/marker-menu/bind-camera-to-markers.png){.icon} Bind Camera to Markers | Makes the selected object the active camera from this marker on. Adds a marker if there is none. Any object can be bound, which lets you switch cameras during the animation. The marker shows a camera icon |
| Rename Marker | Renames the active marker |
| Move Marker | Moves the selected markers. Listed to show its hotkey |
| Select › | **All**, **None**, **Invert**, **Before Current Frame**, **After Current Frame** |
| Jump to Next Marker | Moves the time cursor to the next marker |
| Jump to Previous Marker | Moves the time cursor to the previous marker |
