Keymap Table

● reviewedBforartists 5.3🕒 43 min read

Every hotkey of the Bforartists keymap, editor by editor and mode by mode. The list is written from the Bforartists source each week, so it always matches the current version. To see the keys on a keyboard, or the Blender and Industry Compatible presets, use Standard Keymaps.

Note: The keys are for Windows and Linux. On macOS, most Ctrl keys use Cmd instead. Active tool keys and the keys that only work while a tool runs (for example X, Y and Z to lock an axis while moving) are left out.
